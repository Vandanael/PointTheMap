Point The Map

About this geography game

What is Point The Map?

Point The Map is a small browser geography game where you place countries, cities, or locations on a blank world map in five guesses.

No installation, no account — just quick rounds you can play in one or two minutes.

How it works

  • Choose a mode (countries, capitals, etc.)
  • You get 5 guesses
  • After each guess, the map shows the distance
  • Try to be as accurate as possible
  • Play again instantly, no signup

Privacy

  • No account required
  • No personal data stored
  • No ads inside the game
  • Only anonymous, cookie-free analytics via Plausible

No emails. No profiles. No selling data.

Why this game exists

Point The Map was created as a simple way to mix fun and geography during short breaks.

It is meant to stay lightweight, fast, and slightly challenging without pressure.

What's next

  • A chill 10-second version to take your time
  • Mobile and UI improvements
  • Stats and score recovery features
  • Performance optimizations
  • Login system (only if users request it)

Qu'est-ce que Point The Map ?

Point The Map est un petit jeu de géographie jouable dans le navigateur où vous placez des pays, villes ou lieux sur une carte du monde vide en cinq essais.

Pas d'installation, pas de compte, juste des parties rapides de une ou deux minutes.

Comment jouer

  • Choisissez un mode (pays, capitales, civilisations, stades de foot)
  • Vous avez 5 essais
  • Après chaque tentative, la carte affiche la distance
  • Essayez d'être le plus précis possible
  • Rejouez instantanément, sans inscription

Vie privée

  • Aucun compte requis
  • Aucune donnée personnelle stockée
  • Pas de publicité dans le jeu
  • Uniquement des statistiques anonymes, sans cookies, via Plausible

Pas d'emails. Pas de profils. Pas de revente de données.

Point The Map a été créé pour mélanger plaisir et géographie pendant de courtes pauses.

Le but est de rester léger, rapide et compétitif sans pression.
